外部から来るイベント列の文法 (種別ごとの順序と回数、どのイベントがどの情報を決めるか、情報が来ないことがいつ確定するか) が定義されているか。

検出手順: diff 内で外部からのイベント・メッセージ・コールバックを受け取る箇所 (on / handle / switch(method) / addEventListener) を列挙し、各ハンドラについて「このイベントは何回来るか、どの順で来るか、来ないことがいつ確定するか」がコード近傍かドキュメントに書いてあるかを答える。書いていない状態遷移が if と let の羅列で表現されていれば指摘対象。
匂い: 同じ関数内の複数の `let` フラグ、`if (received && !done)` のようなフラグ同士の条件、ハンドラ内で他のハンドラの副作用を前提にした処理、「順序」「タイミング」に触れないハンドラのコメント。
