diff が、その言語・フレームワークの定番の落とし穴を踏んでいないか。

検出手順: diff の言語とフレームワークを特定し、その定番の落とし穴を書き出してから、diff が持ち込んだ該当箇所を全て列挙する。例: JavaScript の falsy な 0、`==` の型変換、ループ変数を捕まえるクロージャ、`forEach` の中の `await`、文字列長とバイト長の混同。Python の可変な既定引数、遅延束縛のクロージャ。Go の nil map への書き込み、range 変数の捕捉。シェルの未クォートの変数展開、`set -e` が効かない位置のコマンド、パイプの途中の失敗。SQL の文字列連結。タイムゾーンと DST、浮動小数の等値比較。

判定規則: 指摘には、落とし穴が発現する具体的な入力・状態と、誤った結果を 1 つ添える。
