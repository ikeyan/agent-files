diff が変えた振る舞いを、失敗しうるテストか検査が固定しているか。

検出手順: diff が追加・変更した振る舞い (分岐、エラー経路、既定値、出力の形、走査や優先の順序) を全て列挙し、各々について、その振る舞いを元に戻したら失敗するテスト・検査を引用する。引用できなければ指摘する。diff が削除・緩和したテストは、固定していたケースを書き出し、別のテストが引き継いでいるかを答える。
匂い: テストの無い新しい分岐, 削除された test / it, `skip` / `only` / 緩められた assert, 期待値を実装に合わせて書き換えただけのテスト変更
判定規則: 「手で確かめた」は是認理由にならない。テストにできない実行時契約 (権限、環境変数、orchestrator) は、実測の記録が PR 説明・コミット本文にあれば足りる。
