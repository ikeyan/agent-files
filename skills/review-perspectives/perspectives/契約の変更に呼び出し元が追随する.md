変更された関数・スクリプト・設定項目の契約 (事前条件、戻り値の形、投げる例外とその文言、呼ぶ順序とタイミング) の変化に、全ての呼び出し元が追随しているか。

検出手順: diff が本体かシグネチャを変えた関数・スクリプト・設定項目を全て列挙し、各々を名前で Grep して呼び出し元を全て書き出す。呼び出し元ごとに、新しい事前条件を満たすか、変わった戻り値の形と新しい例外を扱うか、順序の前提が保たれるかを答える。同じ diff が callee の契約も変えていれば、diff 内の呼び出しがそれに合っているかも答える。
また、diff が削除・変更したエラーメッセージ・exit code・ログ文言・フィールド名の文字列を全て列挙し、各々をリポジトリ全体で Grep する。変更後もその古い文字列を比較・分岐に使っている箇所が残っていれば指摘する。
匂い: 引数の追加・並べ替え, 戻り値に null や別の型が加わる, 新しい throw / 非ゼロ exit, 削除された throw のメッセージ, `message.includes(…)` や exit code での分岐, 同期から非同期への変更, diff に現れない呼び出し元
判定規則: 「diff 内の呼び出し元は直っている」「例外は try-catch で捕まる」は是認理由にならない。指摘には、壊れる呼び出し元の箇所を引用する。
