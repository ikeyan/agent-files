基盤ツールの失敗を、独自の文言で包み直して本来のエラーを隠していないか。

検出手順: diff で追加された、コマンド・ツールの失敗を捕まえて独自のメッセージを出す箇所を全て列挙する。各々について、元のエラーを隠すか、実際と違う原因を示しうるか (node の crash をファイルが古いと報告する等) を書き出す。隠すなら、包みを外して失敗をそのまま見せる案を出す。
匂い: `|| { echo "ERROR…"; exit 1; }`, stderr を /dev/null に捨ててから独自メッセージ, catch して固定文言で再送出
判定規則: 前提の検査 (道具が無い等) の明示は残してよい。失敗を防ぎたいだけなら最小の構成にする (生成物の上書きは `gen >/dev/null && gen >file`。git 管理下での temp+mv の atomic 化は過剰)。
