規則を述べる文が、採る規則を 1 回述べるだけになっているか。

検出手順: diff で追加・変更された箇条書きの項目・文を全て列挙し、各項目について次を行う。
1. その項目が読者に求める行動を、肯定形の 1 節 (「〜で決める」「〜する」) で書き出す。これを「採る規則」とする。
2. 項目の残りの節を全て列挙し、各節を次の順に判定して、最初に当てはまった分類にする。
   1. 真偽を持つ事実の節 (「Y1 は〜する」「〜は読めない」「〜が付く」): 命題 C にして「C が偽なら、1 の採る規則は別の規則になるか」を答える。
      - なる: 前提。1 文の事実として残す。外部依存の事実なら canon に置いて参照にする。
      - ならない: 事情。
   2. 採らないことを述べる節 (「Y1 でなく」「Y1 では決めない」「Y1 のためと〜しない」「Y1 前提で〜しない」、肯定形の「Y1 でも Z する」): 主語 X を簡潔に補って「X は Y1 でなく Y2」の形にし、「X は Y1 かつ Y2」が成り立ちうるかを答える。
      - 成り立ちえない (Y2 を採れば Y1 は採れない): 代案の否定。
      - 成り立ちうる (Y2 を満たしたまま Y1 もできる): Y1 をしないことは独立した規則。
   3. 1 の採る規則だけから導ける節 (採る規則を別の場面に当てはめ直しただけのもの): 帰結。
   4. 命題にできない節 (「試した」「最初は」「〜の指摘」、出典): 事情。
   5. それ以外の行動を求める節: 独立した規則。
3. 代案の否定・帰結・事情に分類した節を全て削った項目を書き換え案として出す。削る節があれば 1 件の指摘にする。
匂い: でなく, ではなく, では決めない, でも, のためと, 前提で, not X but, instead of, regardless of, even if, 否定や帰結の後に続く括弧書き
判定規則:
- 「全周の再構築でなく変更点に絞ったプローブでよい」: X = 検証の範囲。全周の再構築をしつつ変更点に絞ることはできないので、「全周の再構築でなく」は代案の否定。
- 「書くこと: テストの目的 (手順ではなく)」: X = テストについて書くこと。目的と手順の両方を書けるので、「手順は書かない」は独立した規則。
- Y2 と対にならない「その行為をしないこと」自体が守る制約 (「トークンを引数に載せない」): 独立した規則。
- 「書くかどうかは実行者が誤った行動をするかで決める (cc-web でも canon を足せば読める)」: C = cc-web で canon を読める。偽でも採る規則は変わらないので、括弧書きは事情。
- 「検証は sonnet に渡す。haiku は誤った候補の主張をそのまま確定にする」: C = haiku は誤った候補を確定にする。偽なら haiku で足りて採る規則が変わるので、前提として残す。
- 「Z (Y ではない)」への言い換え、理由の追記、帰結の節を残すことは解ではない。
