diff の各行に、その行を誤らせる入力・状態・タイミング・プラットフォームがあるか。

検出手順: diff の hunk を 1 行ずつ全て読み、各 hunk を含む関数の全体を読む (その関数の変更されていない行のバグも対象)。各行について「どんな入力・状態・タイミングならこの行は誤るか」に答え、答えがある行を全て列挙する。見るもの: 条件の反転・誤り、境界の off-by-one、null / undefined / 欠けたフィールドの参照と分割代入、`await` の抜け、0 や空文字を欠落として扱う判定、コピペでの変数の取り違え、catch での握りつぶし、reject されたまま残る Promise の連鎖、エスケープしていない正規表現のメタ文字。
匂い: 外部から来た値への `as` と直後の分割代入, `.then(` の連鎖の末尾に catch が無い, `if (!x)` で 0 や `""` が正当な値, `<` と `<=` の境界, 似た名前の変数が並ぶ行, 空の catch
判定規則: 指摘には、引き金になる具体的な入力・状態と、誤った結果 (例外、誤った値、止まる処理) を 1 つ添える。添えられないものと、挙動に影響しない書き方の好みは指摘にしない。
