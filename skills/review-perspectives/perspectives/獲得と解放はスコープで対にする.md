資源の獲得と解放が、言語のスコープ終端の仕組みで対になっているか。

検出手順: diff で追加された資源の獲得 (ファイル・ロック・接続・一時ディレクトリ・サブプロセス・リスナー) を全て列挙し、各々の解放がどこにあるかを書き出す。手動の try/finally や末尾での解放で、獲得から try に入るまでの間に例外で抜けうるなら、context manager / `using` / defer / RAII に載せる案を出す。
匂い: 獲得と try の間に文がある, finally の中の close / release / unlock, 関数末尾だけにある cleanup, 早期 return の前に解放が無い
